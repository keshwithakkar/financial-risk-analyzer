# 💰 Financial Risk Analyzer

An AI-powered Machine Learning application that predicts the risk of loan default based on applicant and loan information.

## 🚀 Features

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Loan default prediction
- Random Forest Machine Learning model
- Default probability estimation
- Interactive Streamlit web application
- Low Risk / High Risk classification

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- SciPy
- Joblib
- Streamlit
- Jupyter Notebook

## 🤖 Machine Learning

The project compares:

- Logistic Regression
- Random Forest Classifier

Random Forest achieved approximately **93.55% accuracy** and **0.93 ROC-AUC** on the test dataset.

## 📊 Output

The application provides:

- Risk classification
- Estimated default probability
- Visual probability indicator

## ⚠️ Disclaimer

This tool provides an ML-based risk estimate for demonstration purposes only. It should not be used as the sole basis for financial decisions.
